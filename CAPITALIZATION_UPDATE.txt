CrossCheck Capitalization Update

Updated frontend display text throughout the project so important labels, headings, placeholders, buttons, navigation text, form text, and feature descriptions begin with capital letters.

Examples:
- Full Name
- Email Address
- Register As
- Confirm Password
- Welcome Back
- Create An Account
- Detect Multiple Active Offers And Track Offer History.

Email address values and user-entered data are not force-capitalized.
Backend functionality is unchanged.

CrossCheck Mail Service Merge
=============================

The mail service from CrossCheck-Main-main has been added to this latest CrossCheck project.

Included:
- Spring Boot Mail dependency
- EmailService.java
- SMTP environment-variable configuration
- Registration and password-reset emails
- Candidate added/updated, document, verification, offer-letter, and hiring update emails
- Gmail App Password setup instructions

Mail is disabled by default. Configure the variables in EMAIL_SERVICE_SETUP.md before starting the backend.
